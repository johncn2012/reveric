MetaArc 使用与支持指南

欢迎查阅 MetaArc 元弧官方指南。涵盖客户端安装、账号注册、算力配额流转、多模态任务调度与常见问题排查。

下载与安装指南

访问首页下载更新专区获取官方安装包。安装包均由 MetaArc 官方构建与签名发布：

  • Windows：支持 Windows 10/11 64 位系统。下载安装包并按向导完成安装，首次启动将自动初始化创作环境。
  • macOS：原生针对 Apple Silicon（M 系列芯片）深度优化，提供极速图形渲染与音视频生成体验。
  • Android：支持 Android 10+ 移动设备（arm64 架构），随时随地构思剧情与跟进任务执行进度。
  • 安全提示：请始终通过官方域名（metaarc.com.cn）下载客户端，确保安装文件完整且未被篡改。

账号与安全管理

创作者可在用户中心通过手机号或常用邮箱快捷注册与登录，新账号初始密码长度至少为 6 位。

  • 个人资料：登录后可随时维护个性化笔名昵称与绑定手机。
  • 密码与会话安全：修改登录密码或执行「退出其他会话」后，将即时撤销其他设备的网页登录态，保障账号资产安全。
  • API 客户端密钥：系统为每位创作者自动签发专属大模型网关访问密钥，支持随时一键查看、复制或重置轮换。

找回与重置密码

为保障小说原创成果与账户算力资产的绝对安全，如您遗忘密码，请使用注册邮箱发送申请至官方客服信箱：contact@metaarc.com.cn。我们将在核验账号信息后为您协助重置临时密码。

套餐权益与算力机制

MetaArc 采用透明的算力点数计费机制。文本推演、小说分镜生成、超清配图与视频渲染均按实际消耗的模型 Token 与算力梯度扣除：

  • 基础体验版：新注册用户即刻赠送 500 算力点数与 500MB 云端存储，畅享轻量文字润色与配图体验。
  • 创作者版 / 专业版 / 工作室版：解锁更高并发度、高速 CDN 独享存储以及优先任务队列调度。
  • 订阅与扩充：支持对公转账、商务专属定制及批量点数充值，订单生成后可由商务顾问开具正式发票。

开放 API 与第三方客户端接入

MetaArc 提供符合 OpenAI / Anthropic 业界标准的统一多模态网关。创作者中心签发的专属密钥可直接对接兼容生态：

  • 接口兼容标准：完全兼容 OpenAI /v1/chat/completions、/v1/embeddings 及多模态图片生成协议。
  • 服务请求地址 (Base URL)：https://metaarc.com.cn/v1 或由控制台「个人空间」提供的专属网关节点地址。
  • 客户端配置：支持在 Cherry Studio、NextChat、Chatbox 等主流工具中填入您的 sk-metaarc-... 密钥即可直接调用。
  • 配额与用量同步：第三方客户端调用所消耗的 Token 将实时折算为 MetaArc 算力点数并同步计入消费明细。

技术支持与问题诊断

如果在客户端使用、任务排队或大模型输出阶段遇到任何疑问，我们提供全方位技术保障服务：

  • 官方支持邮箱：contact@metaarc.com.cn（建议附带客户端版本号、日志及截图，我们通常在 2 小时内响应）
  • 商务咨询微信：metaarc_service（工作日 09:00 - 21:00 专属顾问在线支持）
  • 云端服务监控：创作者中心实时提供底层服务健康与任务调度状态透明反馈。
