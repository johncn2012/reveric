帮助中心

安装、账号和发布状态

这里只说明现在能做的事。支付、找回密码和诊断工单还没有接通，页面不会显示一个不存在的订单号或工单号。

下载与安装

先看下载更新。只有更新清单返回了真实安装包时，对应平台才会出现下载链接。没有安装包时保持「尚未发布」，不要从别处寻找替代包。

  • Windows 若显示未签名内测，表示这份安装包没有完成代码签名。安装前请核对版本号和下载域名。
  • macOS 与 Android 在清单没有对应文件时不能下载。
  • 安装包只来自 MetaArc 自己的下载地址。帮助页不提供其他网站的安装包。

账号

用邮箱或手机号在用户中心注册和登录。密码至少 6 位。注册后可以修改昵称和密码，并查看最近登录记录。

退出其他网页会话只对带有会话版本的登录生效。更早的客户端登录会保留到它自己过期，这里不会把它说成已经退出。

找回密码

找回密码尚未开通。用户中心不会显示「邮件已发送」。请写信到 contact@metaarc.com.cn，说明注册时使用的邮箱或手机号。

套餐与点数

在线支付尚未开通，不能购买、续费或开发票。没有订单时，订单页保持空态。页面上的价格只在能读到套餐时显示。

账户上的剩余点数和累计发放来自账号资料。文本、图像、视频还没有分开记账，页面不会编造分类用量。

诊断与支持

这个网站没有诊断工单，不能生成工单编号，也看不到独立上传服务里的文件。安装、登录或生成遇到问题时，把平台、版本和现象写到 contact@metaarc.com.cn。

创作任务和云端文件如果账号里确实有记录，会在用户中心或管理员工作台按原样列出。没有记录就显示空态。
